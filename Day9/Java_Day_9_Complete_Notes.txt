1. WHAT IS POLYMORPHISM?
------------------------
Polymorphism means "many forms".

Java polymorphism covered today:
- Method Overloading
- Method Overriding
- Runtime Polymorphism

2. METHOD OVERLOADING
---------------------
Same method name with different parameter lists.

Example:
void runTest()
void runTest(String URL)
void runTest(String URL, int timeout)

Parameters can differ by:
- Number
- Type
- Order

Return type alone cannot create overloading.

3. METHOD OVERRIDING
--------------------
A child class provides its own implementation of a parent method.

Example:

class BrowserTest
{
    void runTest()
    {
        System.out.println("Running browser test");
    }
}

class SeleniumTest extends BrowserTest
{
    @Override
    void runTest()
    {
        System.out.println("Running Selenium test");
    }
}

@Override helps Java verify that the method is actually overriding
a parent method.

4. RUNTIME POLYMORPHISM
-----------------------
A parent reference can point to a child object:

BrowserTest test = new SeleniumTest();

When:
test.runTest();

is called, Java uses the overridden method from SeleniumTest.

This is Runtime Polymorphism.

5. FINAL QA AUTOMATION EXERCISE
-------------------------------
Parent class:

class BrowserTest
{
    private String browser;
    private String testName;

    BrowserTest(String browser, String testName)
    {
        this.browser = browser;
        this.testName = testName;
    }

    public String getBrowser()
    {
        return browser;
    }

    public void setBrowser(String browser)
    {
        this.browser = browser;
    }

    public String getTestName()
    {
        return testName;
    }

    public void setTestName(String testName)
    {
        this.testName = testName;
    }

    void runTest()
    {
        System.out.println("Running " + testName + " on " + browser);
    }

    void runTest(String URL)
    {
        System.out.println("URL: " + URL);
    }

    void runTest(String URL, int timeout)
    {
        System.out.println("Timeout: " + timeout + " Seconds");
    }
}

Child class:

class SeleniumTest extends BrowserTest
{
    private String application;

    SeleniumTest(String browser, String testName, String application)
    {
        super(browser, testName);
        this.application = application;
    }

    public String getApplication()
    {
        return application;
    }

    public void setApplication(String application)
    {
        this.application = application;
    }

    @Override
    void runTest()
    {
        System.out.println("Running Selenium " + getTestName());
        System.out.println("Application: " + application);
        System.out.println("Browser: " + getBrowser());
    }
}

6. CHILD OBJECT
----------------
SeleniumTest test =
    new SeleniumTest(browser, testName, application);

test.runTest();
test.runTest(URL);
test.runTest(URL, timeout);

The no-argument runTest() is overridden in SeleniumTest.

The parameterized runTest() methods are inherited from BrowserTest.

7. PARENT REFERENCE + CHILD OBJECT
-----------------------------------
BrowserTest test1 =
    new SeleniumTest(browser, testName, application);

test1.runTest();
test1.runTest(URL);
test1.runTest(URL, timeout);

Reference type:
BrowserTest

Actual object:
SeleniumTest

The no-argument runTest() executes the SeleniumTest version.

8. IMPORTANT DIFFERENCE
------------------------
OVERLOADING:
Same method name + different parameters.

Example:
runTest()
runTest(String URL)
runTest(String URL, int timeout)

OVERRIDING:
Child class provides a new implementation of a parent method.

Example:
BrowserTest.runTest()
        ↓
SeleniumTest.runTest()

RUNTIME POLYMORPHISM:
Parent reference + child object.

Example:
BrowserTest test = new SeleniumTest(...);
