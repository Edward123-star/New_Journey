1. THIS KEYWORD
==================================================

The 'this' keyword refers to the current object.

Example:

class Test
{
    String name;
    String platform;
    boolean status;

    Test(String name, String platform, boolean status)
    {
        this.name = name;
        this.platform = platform;
        this.status = status;
    }
}

Here:
- this.name -> instance variable belonging to the current object
- name -> constructor parameter
- this.platform -> object's platform
- platform -> parameter
- this.status -> object's status
- status -> parameter

Easy rule:
this = "this current object"

'this' is commonly used when an instance variable and a parameter have the same name.

It can also be used without a same-name parameter:

void showName()
{
    System.out.println(this.name);
}

2. STATIC VS NON-STATIC
==================================================

Non-static variables belong to individual objects.

Example:

class Test
{
    String testName;
    String platform;
}

Test test1 = new Test();
Test test2 = new Test();

test1.testName = "Login Test";
test2.testName = "Payment Test";

Each object has its own testName.

Static variables belong to the class and are shared.

Example:

class Test
{
    static String company = "Sun Technologies";

    String testName;
}

The static variable can be accessed using the class name:

System.out.println(Test.company);

Remember:

Non-static = each object has its own value.
Static = shared by the class.


STATIC METHODS
--------------

A static method belongs to the class.

Example:

class basics
{
    static void showMessage()
    {
        System.out.println("Hello");
    }

    public static void main(String[] args)
    {
        showMessage();
    }
}

The main() method is static, which is why Java can start it without creating an object of the class.

A non-static method belongs to an object.

Example:

class Test
{
    String name;

    void showName()
    {
        System.out.println(name);
    }
}

To call it:

Test test1 = new Test();
test1.name = "Login Test";
test1.showName();

4. ENCAPSULATION
==================================================

Encapsulation means protecting an object's data and controlling how it is accessed or modified.

Without encapsulation:

class Test
{
    String name;
}

Anyone could directly modify it:

test1.name = "Login Test";

With encapsulation:

class Test
{
    private String name;
}

The variable cannot be directly accessed from outside the class.

We use getters and setters.


PRIVATE
-------

private protects the variable from direct outside access.

Example:

private String name;


SETTER
------

A setter changes the value.

Example:

public void setName(String name)
{
    this.name = name;
}

Think:
set = change the value


GETTER
------

A getter reads the value.

Example:

public String getName()
{
    return name;
}

Think:
get = give me the value


COMMON PATTERN
--------------

private String name;

public void setName(String name)
{
    this.name = name;
}

public String getName()
{
    return name;
}

5. ENCAPSULATION EXERCISE — COMPLETED
==================================================

The exercise was to create private variables for:

name
platform
result

Then create getters and setters and take input from the user.

Completed solution:

import java.util.Scanner;

class Testcase
{
    static String projectName;

    private String name;
    private String platform;
    private boolean result;

    public void setname(String name)
    {
        this.name = name;
    }

    public String getname()
    {
        return name;
    }

    public void setplatform(String platform)
    {
        this.platform = platform;
    }

    public String getplatform()
    {
        return platform;
    }

    public void setresult(boolean result)
    {
        this.result = result;
    }

    public boolean getresult()
    {
        return result;
    }
}

class basic3
{
    public static void main(String[] args)
    {
        Scanner scan = new Scanner(System.in);

        System.out.print("Enter the project Name: ");
        Testcase.projectName = scan.nextLine();

        Testcase test1 = new Testcase();

        System.out.print("Enter test name: ");
        String name = scan.nextLine();

        System.out.print("Enter platform: ");
        String platform = scan.nextLine();

        System.out.print("Enter Result(True/False): ");
        boolean result = scan.nextBoolean();

        test1.setname(name);
        test1.setplatform(platform);
        test1.setresult(result);

        System.out.println("Project: " + Testcase.projectName);
        System.out.println("Details of the " + name);
        System.out.println(test1.getname());
        System.out.println(test1.getplatform());
        System.out.println(test1.getresult());
    }
}

6. JAVA NAMING CONVENTION
==================================================

The code works with:

setname()
getname()
setplatform()
getplatform()
setresult()
getresult()

However, standard Java naming convention is:

setName()
getName()

setPlatform()
getPlatform()

setResult()
getResult()

This is a naming/style improvement, not a functionality error.

==================================================

Inside the setter:

public void setName(String name)
{
    this.name = name;
}

Flow:

User input
    |
    v
String name
    |
    v
test1.setName(name)
    |
    v
setName(String name)
    |
    v
this.name = name
    |
    v
private name is updated

To read it:

test1.getName()

8. STATIC + ENCAPSULATION TOGETHER
==================================================

Static and encapsulation solve different problems.

Static answers:
"Does this value belong to the class or to each object?"

Encapsulation answers:
"How should this data be protected and accessed?"

Example:

static String projectName;

private String name;

projectName is shared by the class.

name belongs to each object and is protected using private.
